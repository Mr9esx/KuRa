# 收纳系统 3D 编辑器放置规则规范 v1.0

## 1. 概述

本文档定义了收纳系统 3D 在线编辑器中，用户将 Item（功能件）和 Riser（增高件）放入 Block（框体）时必须遵守的全部放置规则。目标读者为实现放置规则引擎的开发者或大语言模型。

用户交互流程：用户先选择一个 Block，然后从 Item/Riser 清单中拖拽模块放入 Block 内腔，系统实时验证放置合法性。

## 2. 基础概念

### 2.1 坐标系与网格

- **Cell**：最小网格单元，尺寸 `40 x 40mm`
- **坐标系**：以 Block 内腔左前角为原点
  - X 轴：沿 Block 长边方向（左→右）
  - Y 轴：沿 Block 短边方向（前→后）
  - Z 轴：高度方向（底→顶）
- **Cell 坐标**：`(col, row)`，其中 `col` 沿 X 轴从 0 开始，`row` 沿 Y 轴从 0（最前排）开始

### 2.2 模块类型

| 类型 | 说明 | 高度档位 |
|---|---|---|
| **Block** | 框体容器，内腔尺寸为 `40n x 40m`，前低后高斜面设计 | 前 Border 12mm，后 Border 72mm |
| **Item** | 功能收纳件，放在 Block 内腔底板上或 Riser 上方 | `H20 / H40 / H80`（即 20mm / 40mm / 80mm） |
| **Riser** | 增高垫块，放在 Block 底板与 Item 之间 | `R5 / R10 / R20`（即 5mm / 10mm / 20mm） |

### 2.3 Block 几何参数

所有 Block 共享以下几何规则：

- 底部厚度：`4mm`
- 壳体 Border 厚度：`4mm`
- 前 Border 总高度：`12mm`（含底厚 4mm，**净高 8mm**）
- 后 Border 总高度：`72mm`（含底厚 4mm，**净高 68mm**）
- 左右侧 Border：从前到后线性斜面过渡，总高度从 12mm 升至 72mm
- 外轮廓尺寸：`外长 = 内长 + 8mm`，`外宽 = 内宽 + 8mm`

### 2.4 侧壁净高计算公式

Block 左右侧壁为线性斜面，不同行位置的侧壁净高不同。

通用公式（适用于所有 Block 规格）：

```
设 Block 内腔宽度（前后方向）为 W（单位 mm）
外腔宽度 = W + 8

该行后沿的内腔位置 p = (row + 1) × 40       （mm）
对应外壁位置         d = p + 4                 （mm）
该处侧壁总高度       H_total = 12 + 60 / (W + 8) × d  （mm）
该处侧壁净高         H_net = H_total - 4       （mm）
```

## 3. 放置规则

### 规则 R1：网格对齐

**所有 Item 和 Riser 必须对齐到 `40x40mm` 的 Cell 网格。**

- Item 和 Riser 的 XY 尺寸必须为 `40` 的正整数倍，即 `40n x 40m`（n, m >= 1）
- 放置时 Item/Riser 的左前角必须落在某个 Cell 的左前角上
- 拖拽过程中应实现网格吸附效果

**示例：** 一个 `80x40mm`（2x1）的 Item 放在 Cell 坐标 `(2, 1)` 处，表示它占用 `(2,1)` 和 `(3,1)` 两个 Cell，其左前角实际坐标为 `(80mm, 40mm)`。

---

### 规则 R2：容器边界

**Item 和 Riser 不能超出 Block 的内腔范围。**

- Block 内腔尺寸为 `40n x 40m`，总共 `n x m` 个 Cell
- 放置的模块占用的所有 Cell 都必须在 `(0,0)` 到 `(n-1, m-1)` 范围内

**示例：** 标准 Block `240x160mm` 的内腔为 `6x4` Cell。一个 `120x40mm`（3x1）的 Item 放在 `(4, 0)` 处，会占用 `(4,0)`、`(5,0)`、`(6,0)`，其中 `(6,0)` 超出 col 范围（最大 col=5），不合法。

---

### 规则 R3：同层不重叠

**同一 Z 层面上的模块不能重叠占用 Cell。允许 Cell 留空。**

- 两个 Item 不能占用相同的 Cell
- 两个 Riser 在同一叠加层也不能占用相同的 Cell
- Cell 可以不放任何东西（留空）

**示例：**

```
Block 6x4 的 row 0，共 6 个 Cell：

合法：
  col:  0   1   2   3   4   5
      [Item A 2x1] [ 空 ][ 空 ] [Item B 2x1]
  → (2,0) 和 (3,0) 留空，无重叠，合法

不合法：
  col:  0   1   2   3   4   5
      [Item A 2x1][Item B 2x1]
       占(0,0)(1,0) 占(1,0)(2,0)
  → (1,0) 同时被 A 和 B 占用，不合法
```

---

### 规则 R4：Riser 位于 Item 下方

**Riser 只能放在 Block 底板与 Item 之间，作为 Item 的垫高支撑。**

- 不是每个 Item 都需要 Riser，没有 Riser 的 Item 直接放在底板上
- Riser 不能独立存在（上面必须有 Item）
- Z 轴结构从下往上为：`底板 → [Riser 层1] → [Riser 层2] → ... → Item`

---

### 规则 R5：Riser 底面全支撑

**Riser 必须完整铺满其上方 Item 底面的每一个 Cell，且同一层所有 Riser 必须等高。**

- 如果 Item 占用 N 个 Cell，其下方同一层的 Riser 也必须覆盖全部 N 个 Cell，不能有缺口
- 可以用多个小 Riser 拼接覆盖，但必须无缝、无重叠、等高

**示例 1（合法 — 拼接覆盖）：**

```
80x80mm（2x2）Item 下面放 2 个 80x40mm（2x1）R10 Riser 并排：

俯视图：
  Item (2x2):     占 (0,0)(1,0)(0,1)(1,1)
  Riser A (2x1):  占 (0,0)(1,0)  → R10
  Riser B (2x1):  占 (0,1)(1,1)  → R10
  → 4 个 Cell 全覆盖，两个 Riser 都是 R10（等高）→ 合法
```

**示例 2（不合法 — 未铺满）：**

```
80x80mm（2x2）Item 下面只放 1 个 80x40mm（2x1）R10 Riser：

  Item (2x2):     占 (0,0)(1,0)(0,1)(1,1)
  Riser (2x1):    只占 (0,0)(1,0)
  → (0,1)(1,1) 下方悬空，Item 会倾倒 → 不合法
```

**示例 3（不合法 — 不等高）：**

```
80x80mm（2x2）Item 下面放 1 个 R10 + 1 个 R20，虽然覆盖全部 Cell：

侧视图：
       ┌──────────────────┐
       │    Item 2x2      │ ← 倾斜
  ┌────┘                  └─────┐
  │  Riser R10  │  Riser R20   │
  └─────────────┴──────────────┘
  → 前半 10mm、后半 20mm，不等高，Item 倾斜 → 不合法
```

---

### 规则 R6：Riser 叠加

**Riser 可以叠放多层，无层数上限。每层独立遵守 R5。**

- 叠加的多层 Riser 高度累加
- 每一层 Riser 都必须完整铺满上层底面，且该层内等高
- 总高度受 R7 约束

**示例（合法）：**

```
80x40mm（2x1）Item 下面叠 3 层 R20：

侧视图：
  ┌─────────┐
  │  Item   │  H40
  ├─────────┤
  │ Riser 3 │  R20
  ├─────────┤
  │ Riser 2 │  R20
  ├─────────┤
  │ Riser 1 │  R20
  └─────────┘
  底板

  Riser 总高度 = 60mm
  → 需通过 R7 校验才最终合法
```

---

### 规则 R7：Riser 高度约束（核心规则）

**一个 Item 下方的 Riser 总高度必须严格小于其前、后、左、右四个方向上约束值的最小值。**

这是整个放置系统最重要的规则。它统一了所有高度相关的约束——邻接 Item、Block 边框、空位——用同一套逻辑判定。

#### 7.1 四个方向的约束值

对于一个放置在某位置的带 Riser 的 Item，其四个方向（前、后、左、右）各有一个约束值：

| 方向上的情况 | 约束值 | 物理含义 |
|---|---|---|
| 有相邻 Item | 该 Item **自身的高度**（H20/H40/H80，不含其 Riser） | 相邻 Item 的本体能挡住多高 |
| 是 Block 边框 | 该位置处**边框的净高** | 边框能挡住多高 |
| 是空位（无 Item） | **0** | 没有任何东西挡住，无法支撑任何 Riser 高度 |

**边框净高取值：**

| 方向 | 约束值 |
|---|---|
| 前方（row=0 的 Item 前面） | 前 Border 净高 = `8mm` |
| 后方（最后一行 Item 后面） | 后 Border 净高 = `68mm` |
| 左方（col=0 的 Item 左面） | 该行位置处左侧壁净高（见 2.4 公式） |
| 右方（最后一列 Item 右面） | 该行位置处右侧壁净高（与左侧壁对称相等） |

#### 7.2 判定公式

```
约束值列表 = [前方约束值, 后方约束值, 左方约束值, 右方约束值]

合法条件：Riser 总高度 < min(约束值列表)
```

> **严格小于（<），等于不合法。** Riser 高度等于约束值时，Riser 顶面与约束面齐平，上方 Item 的整个本体都暴露在约束面之上，无法被固定住。

> **Item 本身的高度不参与此约束。** Item 可以高出边框或邻居（如 H80 笔筒高出侧壁），只要它底下的 Riser 满足约束即可。Riser 是"地基"，约束的是地基的高度。

#### 7.3 相邻 Item 的判定方法

"相邻"指目标 Item 边界外侧紧贴的 Cell 中是否存在 Item。

对于占用多个 Cell 的 Item（如 2x2），需要检查其每条边外侧的所有 Cell：

- 只要该方向外侧 Cell 中**至少有一个**被 Item 占据，该方向视为"有相邻 Item"
- 约束值取该方向所有相邻 Item 中**最矮的那个**的高度

#### 7.4 跨多行/多列 Item 的边框约束

当一个 Item 跨越多行时（如 2x2 占 row 0 和 row 1）：

- **前方** = 最前排（row 0）前面的约束（前 Border 或 Item）
- **后方** = 最后排（row 1）后面的约束（后 Border 或 Item）
- **左右侧壁**：取该 Item 覆盖的**最前排行后沿**的侧壁净高（最保守值，因为前面的侧壁更矮）

#### 7.5 示例

##### 示例 1：标准布局，合法

```
标准 Block 6x4，所有 Item 均为 2x1（占 2 Cell）：

         col 0-1      col 2-3      col 4-5
row 3:  [H40+R10]    [H40+R10]    [H40+R10]
row 2:  [H40    ]    [H40    ]    [H40    ]
row 1:  [H20    ]    [H20    ]    [H20    ]
row 0:  [H20    ]    [H20    ]    [H20    ]

以 row 3 中间 Item（col 2-3）的 R10 为例：
  前方: row 2 中间 Item → H40 = 40
  后方: 后 Border → 净高 68
  左方: row 3 左侧 Item → H40 = 40
  右方: row 3 右侧 Item → H40 = 40
  min(40, 68, 40, 40) = 40
  R10 = 10 < 40 → 合法 ✓
```

##### 示例 2：等于约束值，不合法

```
同上布局，但想给 row 1 中间 Item 加 R20：

  前方: row 0 中间 Item → H20 = 20
  后方: row 2 中间 Item → H40 = 40
  左方: row 1 左侧 Item → H20 = 20
  右方: row 1 右侧 Item → H20 = 20
  min(20, 40, 20, 20) = 20
  R20 = 20，20 不 < 20 → 不合法 ✗

  原因：Riser 和邻居一样高，Item 本体完全暴露在邻居之上，无固定。
```

##### 示例 3：有空位，Riser 被空位限制

```
         col 0-1      col 2-3      col 4-5
row 1:  [  空   ]    [H40+R? ]    [  空   ]
row 0:  [H20    ]    [H20    ]    [H20    ]

row 1 中间 Item 想加 Riser：
  前方: row 0 中间 Item → H20 = 20
  后方: 空位（row 2 无 Item） → 0
  左方: 空位 → 0
  右方: 空位 → 0
  min(20, 0, 0, 0) = 0
  任何 Riser > 0，不 < 0 → 不合法 ✗

  原因：后方和左右都是空位（约束值=0），无法支撑任何 Riser。
  解法：先在后方或左右放置 Item，提供足够约束后再加 Riser。
```

##### 示例 4：H80 Item 无 Riser，合法

```
标准 Block 6x4：

         col 0-1      col 2-3      col 4-5
row 3:  [H80    ]    [H80    ]    [H80    ]
row 2:  [H40    ]    [H40    ]    [H40    ]
row 1:  [H20    ]    [H20    ]    [H20    ]
row 0:  [H20    ]    [H20    ]    [H20    ]

row 3 的 H80 Item 没有 Riser → Riser 总高度 = 0。
R7 不需要校验（无 Riser 时此规则自动通过）。
H80 高出侧壁净高 66.5mm？没关系，R7 不约束 Item 高度。
H80 笔筒从 Block 后排露出来，是正常使用方式。→ 合法 ✓
```

##### 示例 5：前 Border 约束，不合法

```
标准 Block 6x4：

row 0:  [H20+R10]

row 0 的 Item 靠前 Border：
  前方: 前 Border → 净高 8mm
  后方: 空位 → 0
  左方: 左侧壁 → 净高 23.7mm
  右方: 空位 → 0
  min(8, 0, 23.7, 0) = 0
  R10 = 10，不 < 0 → 不合法 ✗

  即使后方和右方不是空位，前 Border 也只有 8mm：
  前方: 前 Border → 8
  后方: row 1 Item → H20 = 20
  左方: 侧壁 → 23.7
  右方: 同行 Item → H20 = 20
  min(8, 20, 23.7, 20) = 8
  R10 = 10，不 < 8 → 仍然不合法 ✗

  row 0 最多只能用 R5（5 < 8）。
```

##### 示例 6：移除 Item 导致邻接失效

```
初始状态（合法）：

         col 0-1      col 2-3
row 1:  [H40+R5 ]    [H40    ]
row 0:  [H20    ]    [H20    ]

row 1 左侧 Item 的 R5 校验：
  前方: row 0 左侧 H20 = 20
  后方: 后 Border 净高 68
  左方: 侧壁净高 38.0
  右方: row 1 右侧 H40 = 40
  min(20, 68, 38, 40) = 20
  R5 = 5 < 20 → 合法 ✓

用户移除 row 0 左侧的 H20 Item：

         col 0-1      col 2-3
row 1:  [H40+R5 ]    [H40    ]
row 0:  [  空   ]    [H20    ]

重新校验：
  前方: 空位 → 0
  后方: 后 Border 净高 68
  左方: 侧壁净高 38.0
  右方: row 1 右侧 H40 = 40
  min(0, 68, 38, 40) = 0
  R5 = 5，不 < 0 → 不合法 ✗

  前方变空位后，约束值变 0，Riser 不再合法。
  系统应提示用户：移除此 Item 会导致上方 Item 的增高件失效。
```

### 规则 R8：高度档位离散化

**所有高度值只能取规定的离散档位。**

- Item 高度：`20mm`（H20）、`40mm`（H40）、`80mm`（H80）
- Riser 高度：`5mm`（R5）、`10mm`（R10）、`20mm`（R20）
- Riser 叠加后的总高度为各层高度之和（如 R10 + R20 = 30mm）

## 4. 规则校验流程

### 4.1 放置 Item 时的校验

当用户将一个 Item（可能带 Riser）放入 Block 时，按以下顺序校验：

```
步骤 1: [R1] Item/Riser 尺寸是否为 40mm 整数倍？是否对齐到 Cell 网格？
         ↓ 通过
步骤 2: [R8] Item 高度是否为 H20/H40/H80？Riser 高度是否为 R5/R10/R20？
         ↓ 通过
步骤 3: [R2] Item 占用的所有 Cell 是否在 Block 内腔范围内？
         ↓ 通过
步骤 4: [R3] Item 占用的 Cell 是否与已有 Item 冲突？
         ↓ 通过
步骤 5: [R5] 如果有 Riser，是否完整铺满 Item 底面所有 Cell？同层是否等高？
         ↓ 通过
步骤 6: [R6] 如果 Riser 多层叠加，每层是否独立满足 R5？
         ↓ 通过
步骤 7: [R7] 如果有 Riser，Riser 总高度是否 < min(四方向约束值)？
         ↓ 通过
放置合法 ✓
```

### 4.2 移除/移动 Item 时的联动校验

当用户移除或移动一个已放置的 Item 时，该操作可能导致相邻 Item 的 R7 约束失效。系统必须：

1. 识别所有以被移除 Item 为邻接约束来源的 Item
2. 对这些 Item 重新执行 R7 校验
3. 如果有 Item 的 Riser 变得不合法，向用户发出警告

**推荐的交互方式：** 在用户确认移除前，预先高亮所有会受影响变为不合法的 Item，让用户决定是否继续。

## 5. 完整布局示例

### 5.1 经典梯度布局（合法）

```
标准 Block 6x4（240x160mm），所有 Item 为 2x1：

         col 0-1      col 2-3      col 4-5
row 3:  [H40+R10]    [H40+R10]    [H40+R10]    ← Riser R10
row 2:  [H40    ]    [H40    ]    [H40    ]
row 1:  [H20    ]    [H20    ]    [H20    ]
row 0:  [H20    ]    [H20    ]    [H20    ]    ← 最前排

R7 校验 row 3 任意 Item 的 R10：
  各方向约束值均 >= 40（前方 H40、后方后 Border 68、左右 H40 或侧壁）
  min >= 40，R10 = 10 < 40 → 全部合法 ✓

效果：后排高于前排 10mm，形成梯度，方便取物和观察。
```

### 5.2 后排高件布局（合法）

```
标准 Block 6x4，后排放 H80 笔筒：

         col 0-1      col 2-3      col 4-5
row 3:  [H80    ]    [H80    ]    [H80    ]    ← 笔筒，无 Riser
row 2:  [H40    ]    [H40    ]    [H40    ]
row 1:  [H20    ]    [H20    ]    [H20    ]
row 0:  [H20    ]    [H20    ]    [H20    ]

所有 Item 均无 Riser → R7 自动通过（Riser=0 < 任何正数）。
H80 高出侧壁净高 66.5mm？合法，R7 不约束 Item 自身高度。
笔筒从 Block 后排露出来是正常使用方式。→ 合法 ✓
```

### 5.3 带空位的布局（部分合法）

```
标准 Block 6x4：

         col 0-1      col 2-3      col 4-5
row 3:  [  空   ]    [H40+R10]    [H40    ]
row 2:  [H40    ]    [H40    ]    [H40    ]
row 1:  [H20    ]    [  空   ]    [H20    ]
row 0:  [H20    ]    [H20    ]    [H20    ]

R7 校验 row 3 中间 Item 的 R10：
  前方: row 2 中间 H40 = 40
  后方: 后 Border 68
  左方: 空位 → 0         ← 这里是空位！
  右方: row 3 右侧 H40 = 40
  min(40, 68, 0, 40) = 0
  R10 = 10，不 < 0 → 不合法 ✗

解法：在 row 3 col 0-1 处放一个 Item（即使是 H20），就能提供左方约束。
```

### 5.4 大尺寸 Item 布局（合法）

```
标准 Block 6x4，混合不同尺寸的 Item：

         col 0-1      col 2   col 3-4      col 5
row 3:  [H40 2x1]   [      H40 2x2      ] [H40 1x1]
row 2:  [H40 2x1]   [      (续上)       ] [H40 1x1]
row 1:  [H20 2x1]   [H20 1x1][H20 2x1  ] [........]
row 0:  [H20 2x1]   [H20 1x1][H20 2x1  ] [........]

2x2 的 H40 Item 占 (2,2)(3,2)(2,3)(3,3)，无 Riser：
  → Riser = 0，R7 自动通过 ✓

如果想给这个 2x2 Item 加 R5：
  前方: row 1 在 col 2-3 处 → H20(col2) 和 H20(col3-4的一部分)，最矮 H20 = 20
  后方: 后 Border 68
  左方: row 2-3 在 col 1 处 → H40 = 40
  右方: row 2-3 在 col 4 处 → H40(可能) 或空位
  假设右方有 Item H40：min(20, 68, 40, 40) = 20
  R5 = 5 < 20 → 合法 ✓
```

## 6. 规则总览速查

| 编号 | 规则名 | 约束对象 | 一句话描述 |
|---|---|---|---|
| R1 | 网格对齐 | Item / Riser | 尺寸为 40mm 整数倍，位置吸附到 Cell 网格 |
| R2 | 容器边界 | Item / Riser | 不能超出 Block 内腔 |
| R3 | 同层不重叠 | Item / Riser | 同一层的模块不能占用相同 Cell |
| R4 | Riser 在 Item 下方 | Riser | Riser 只在底板和 Item 之间，不能独立存在 |
| R5 | 底面全支撑 | Riser | Riser 必须铺满 Item 底面每个 Cell，同层等高 |
| R6 | Riser 叠加 | Riser | 可多层叠加，每层独立满足 R5，无层数上限 |
| R7 | **Riser 高度约束** | **Riser** | **Riser 总高度 < min(四方向约束值)**，空位=0，边框=净高，Item=自身高度 |
| R8 | 高度档位 | Item / Riser | Item 只取 H20/H40/H80，Riser 只取 R5/R10/R20 |
