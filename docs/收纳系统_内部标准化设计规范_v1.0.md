# 通用收纳系统内部标准化设计规范

## 1. 目标与范围

本规范用于统一收纳系统的尺寸、命名、结构、公差、测试与发布流程，确保模块可复用、扩展可控、制造稳定、体验一致。

适用对象：结构设计、3D 建模、打样测试、生产与文档维护人员。

## 2. 术语定义

- Cell：最小平面网格单元，尺寸 `40 x 40mm`
- Block：底板级区域，标准尺寸 `240 x 160mm`（`6 x 4 Cell`）
- Item：放置物件的功能模块，必须占用整数 Cell
- Riser（增高 Block）：用于制造高度差的垫高模块

## 3. 基础尺寸规范（强制）

### 3.1 XY 网格

- 基准网格：`1 Cell = 40 x 40mm`
- 标准 Block：`240 x 160mm = 6 x 4 Cell`
- 标准 Item：`80 x 40mm = 2 x 1 Cell`
- Item 外形必须为 `40n x 40m`，`n,m` 为正整数

### 3.2 Z 高度体系

- 主高度档：`20 / 40 / 80mm`
- 增高档：`5 / 10 / 20mm`
- 增高叠加上限：最多 `2` 层
- 推荐高度表达：`H20/H40/H80`（主件），`R5/R10/R20`（增高件）

### 3.3 标准 Block 框体几何定义（强制）

标准 Block 由统一框体定义，内部空间为标准收纳区域。

- 内部净空间（长 x 宽）：`240 x 160mm`
- 底部厚度：`4mm`
- 壳体 Border 厚度：`4mm`
- 外圆角：`R4`
- 内圆角：`R2`

前高后低定义（以 Border 顶面高度计）：

- 前 Border 总高度：`12mm`（含底部 `4mm`）
- 后 Border 总高度：`72mm`（含底部 `4mm`）
- 前后高度差：`60mm`

由此可得外轮廓基准尺寸：

- 外长：`240 + 4 + 4 = 248mm`
- 外宽：`160 + 4 + 4 = 168mm`

左右侧 Border 为线性斜边时（沿 168mm 方向从前到后抬升 60mm）：

- 斜边长度：`sqrt(168^2 + 60^2) = 178.39mm`（约 `178.4mm`）
- 斜率：`60 / 168 = 0.3571`
- 坡度角：`atan(60 / 168) = 19.65°`（约 `19.7°`）

建模约束：

1. 前后 Border 高度和底厚必须参数化绑定，禁止独立手改
2. 左右斜边必须为直线过渡（后续若有曲线方案需单独命名）
3. 圆角在斜面与前后面交界处需保持连续，不得出现尖角断面

### 3.4 扩展框体规格与挂载兼容（强制）

除标准框体 `240 x 160` 外，系统允许基于 Item 网格派生不同框体。所有扩展框体必须满足以下规则：

- 内部净空间必须为 `40mm` 的整数倍
- 内部尺寸格式为 `40n x 40m`
- 几何规则与标准框体一致：底厚 `4mm`、Border 厚 `4mm`、外圆角 `R4`、内圆角 `R2`
- 前高后低规则一致：前 Border `12mm`、后 Border `72mm`，左右侧保持线性斜边

框体尺寸上限：

- 普通框体（桌面版）最大内腔：`240 x 160`
- 洞洞板挂载框体最大内腔：`240 x 120`

框体 SKU 当前基线：

普通框体（桌面版，6 个）：

- `41001`：`B-6x4-H72-SHELL`（内腔 `240x160`）
- `41002`：`B-6x2-H72-SHELL`（内腔 `240x80`）
- `41003`：`B-4x4-H72-SHELL`（内腔 `160x160`）
- `41004`：`B-4x2-H72-SHELL`（内腔 `160x80`）
- `41005`：`B-4x1-H72-SHELL`（内腔 `160x40`）
- `41006`：`B-2x1-H72-SHELL`（内腔 `80x40`）

洞洞板挂载框体（5 个）：

- `42001`：`B-6x3-H72-SHELL-PEG`（内腔 `240x120`）
- `42002`：`B-6x2-H72-SHELL-PEG`（内腔 `240x80`）
- `42003`：`B-4x3-H72-SHELL-PEG`（内腔 `160x120`）
- `42004`：`B-4x2-H72-SHELL-PEG`（内腔 `160x80`）
- `42005`：`B-2x1-H72-SHELL-PEG`（内腔 `80x40`）

扩展框体外轮廓尺寸可由统一公式生成：

- 外长 `L_out = L_in + 8`
- 外宽 `W_out = W_in + 8`

命名与发号约束：

1. 框体桌面版统一使用 `41xxx` 段
2. 框体洞洞板版统一使用 `42xxx` 段
3. 同内腔尺寸若出现结构升级（例如加强版），保留原短编号，完整变更必须写入变更日志

#### 3.4.1 IKEA 洞洞板挂载接口（强制）

框体需支持 IKEA 洞洞板挂载。为避免不同批次与地区规格差异，采用“可替换挂载接口 + 板型模板验证”机制。

设计要求：

1. 框体背面必须预留标准挂载接口区（建议接口区宽度不少于 `40mm`）
2. 挂载结构采用可替换式（挂钩件/背板件可独立换代）
3. 挂载孔位与挂钩间距必须通过目标 IKEA 洞洞板实物模板校验后发布
4. 发布时必须在型号说明中标注兼容板型（例如 SKADIS）与最大建议载荷

验证要求：

- 静载测试：额定载荷下保持稳定，不滑脱
- 动载测试：模拟取放冲击后无明显松脱
- 插拔测试：重复挂取后挂载件无开裂、无明显塑性变形

## 4. 配合与公差规范（强制）

- 常规模块外形配合间隙（每侧）：`0.20 ~ 0.40mm`
- 物件槽位分级：
  - `Snug Fit`（紧配）：每侧 `0.15 ~ 0.25mm`
  - `Easy Access`（易取）：每侧 `0.30 ~ 0.60mm`
- 所有槽位必须在图纸中声明配合等级，禁止未标注刚好配合

## 5. 结构规范（强制）

- 长条模块（长度 `>=120mm`）必须增加底部加强结构
- 所有 Riser 顶部与底部必须有定位结构（定位圈、定位柱或等效）
- 面向取物优化的前后分层，后排建议高于前排 `10~15mm`

## 6. 模块最小集合（建议默认提供）

- `1x1`（`40x40`）
- `2x1`（`80x40`）
- `2x2`（`80x80`）
- `3x1`（`120x40`）

说明：缺少 `1x1` 会显著增加格位浪费率。

## 7. 命名规范（强制）

命名格式：`[类别]-[占格]-[高度]-[功能]`

- 类别：`B`（基础容器）、`F`（功能件）、`R`（增高件）
- 占格：如 `2x1`、`3x2`
- 高度：如 `H20`
- 功能：如 `GEN`、`PEN`、`AA`

- 基础收纳
 - B-2x1-H20-八小格

示例：

- `F-2x1-H20-GEN`
- `F-2x1-H40-AA10`
- `R-2x1-H10-STD`

### 7.1 用户短编号规范（强制）

为降低用户记忆成本，所有模块必须提供 5 位数字短编号，格式为：`TTSNN`。

- `TT`（前两位）：类型码（定义大类）
- `S`（第 3 位）：系列码（按场景或规格族分组）
- `NN`（后两位）：流水号（同一 `TT + S` 下自增，范围 `01~99`）

编码示例：

- `11001`：通用收纳系列的第 1 个型号
- `12003`：笔筒系列的第 3 个型号
- `21002`：电池系列的第 2 个型号

类型码建议（可扩展）：

- `11`：通用收纳
- `12`：笔筒收纳
- `21`：电池收纳
- `22`：口红收纳
- `31`：增高件
- `41`：框体（桌面版）
- `42`：框体（洞洞板挂载版）

发号规则：

1. 新型号创建时，由文档维护人登记短编号
2. 不允许复用已发布短编号
3. 已下线型号短编号保留，不回收
4. 用户文档中短编号与完整型号必须一一对应

## 8. 功能件设计规则（强制）

- 先定义场景（静态收纳、频繁取放、运输抗晃）
- 再定义槽位策略（`Snug Fit` 或 `Easy Access`）
- 高频取放件必须有助取结构（手指缺口、顶出孔、导角）
- 重载优先一体式高件，避免多层 Riser 叠高

### 8.1 标准 Item 外形几何（强制）

针对标准 Item 及其扩展 Item（整数 Cell 尺寸），统一外形边界规则如下：

- 四角外圆角：`R2`
- 四角内圆角：`R1`
- 底部四条边：不做圆角，统一采用倒角 `C1`（`1mm`）

建模约束：

1. 外形圆角与底部倒角必须参数化，不允许手工局部修改
2. 对接触承重面的边界，优先保持倒角连续，避免尖角崩边

### 8.2 表面四条边处理规范（圆角 or 倒角）

默认建议：表面四条边采用小倒角 `C0.5`（推荐值），不默认使用圆角。

原因：

- 倒角在 FDM 打印中更稳定，边缘发丝与象脚影响更可控
- 倒角触感改善明显，且不会显著侵占顶部有效面积
- 对标签贴附和阵列视觉对齐更友好

设计决策说明（为何选择 `C0.5`）：

- `C0.5` 已可显著去除锐边，满足日常触摸与取放手感
- 相比 `C1`，对顶部可用平面侵占更小，密集槽位场景更不易挤压功能区
- 对常见 `0.4mm` 喷嘴与 PLA 工艺更友好，可降低首层边缘缺陷对外观的一致性影响
- 作为全型号默认参数易于标准化管理；若个别品类需要更高触感，可按例外规则升级为小圆角

可选例外：

- 高频手持、经常触摸的 Item，可改为小圆角 `R0.8~R1.0`
- 若顶部要与其他件做滑入式配合，优先保持直边或极小倒角 `C0.3~C0.5`

一致性要求：

1. 同一型号内，表面四边处理必须一致，不得混用圆角和倒角
2. 用户文档发布时，需明确标注该型号为“表面倒角版”或“表面圆角版”

## 9. 测试与验收（强制）

每个新模块发布前至少通过以下验证：

- 装入测试：可顺利装入，无暴力按压
- 取出测试：单手可完成
- 抖动测试：轻摇不散落（按场景阈值定义）
- 循环测试：`100` 次取放无明显卡滞、开裂或结构失稳
- 叠层测试：组合状态下无明显错位

## 10. 发布流程（内部）

1. 建模自检（尺寸、公差、命名）
2. 打样验证（至少两套打印参数）
3. 测试记录归档
4. 变更日志更新与发布说明
5. 用户文档与型号总表同步更新

## 11. 附录：AA 电池模块参考（示例）

- 目标：`2x1 Item (80x40)` 放置 `10` 节 AA
- AA 参考尺寸：直径 `14.5mm`，长度 `50.5mm`
- 建议方案：竖放，孔阵列 `5 x 2`
- 孔径建议：
  - 紧配：`14.8 ~ 15.0mm`
  - 易取：`15.2 ~ 15.6mm`
- 必须包含手指缺口或底部顶出孔

## 12. 当前 12 个 Item 规格（强制基线）

本章节定义当前 `12` 个 Item 的统一规格，包含目标物尺寸、公差策略、槽位数量、行列排布、槽间间隔、四边边距和设计建议。

### 12.1 槽位与公差统一规则

- 适用对象：`80x40` 标准 Item（`2x1 Cell`）
- 推荐配合优先级：默认优先使用 `Easy Access`
- `Easy Access`：关键尺寸总间隙 `+0.70 ~ +1.20mm`
- `Snug Fit`：关键尺寸总间隙 `+0.30 ~ +0.50mm`
- 深槽修正：深度 `>15mm` 时，额外增加 `+0.20mm`
- 边距下限：任一方向边距不得小于 `2.0mm`
- 槽间壁厚下限：`1.6mm`（推荐不小于 `2.0mm`）

### 12.3 排布验收要求

1. 任一槽位到边界最小边距不得小于 `2.0mm`
2. 任意两槽位之间最小壁厚不得小于 `1.6mm`
3. 槽位阵列中心偏移（相对 Item 中心）不得超过 `0.5mm`
4. 每个品类必须至少保留“标准容量版”或“易取优先版”中的一种

## 13. 3D 打印工艺规范（强制）

### 13.1 材料与颜色（强制）

- 统一材料：`PLA Matte`
- 统一颜色：`哑光象牙白`
- 适用范围：`Block` 与 `Item` 全型号

### 13.2 通用切片参数（基线）

以下参数作为当前基线，适用于 `0.4mm` 喷嘴设备（FDM）：

| 参数 | 基线值 | 说明 |
|---|---|---|
| 喷嘴直径 | `0.4mm` | 统一硬件基线 |
| 层高 | `0.20mm` | 默认质量档（兼顾速度与精度） |
| 首层层高 | `0.24mm` | 提升首层容错 |
| 线宽（外墙/内墙） | `0.42 / 0.45mm` | 外观与效率平衡 |
| 挤出温度 | `205~215°C`（建议 `210°C` 起） | 按耗材批次微调 |
| 热床温度 | `55°C`（建议区间 `50~60°C`） | 控制附着与翘边 |
| 风扇 | 第 1~2 层关闭，第 3 层起 `100%` | 防止首层过冷翘边 |
| 壁线数（外壳） | `Block: 4`，`Item: 3` | 分级控制成本与强度 |
| 顶层层数 | `5` | 顶面闭合质量基线 |
| 底层层数 | `5` | 与底部强度配合 |
| 缝合位置 | 背面对齐或隐藏对齐 | 降低正面观感缺陷 |

### 13.3 填充策略（强制）

| 对象 | 填充率 | 填充方式 | 说明 |
|---|---:|---|---|
| Block（含挂墙框体） | `20%` | `Gyroid` | 强度稳定，受力均衡 |
| Item（全部功能件） | `15%` | `Gyroid` | 兼顾重量、时长与成本 |

说明：

- 若打印时间压力较大，Item 可降至 `12%`，但需通过强度回归测试
- 不建议使用低于 `10%` 的填充率

### 13.4 表面优化与熨平（建议强）

默认策略：

- 顶面启用熨平（仅最上层）
- 侧壁不启用熨平

推荐参数（各切片器按同义参数映射）：

- 熨平线距：`0.15mm`
- 熨平流量：`10~15%`（建议 `12%`）
- 熨平速度：`20~30mm/s`（建议 `25mm/s`）
- 熨平区域：仅可视顶面

禁用场景：

- 顶面存在高精度配合槽位（避免熨平导致局部尺寸漂移）
- 大面积薄壁顶面（避免热量累积引发表面波纹）

### 13.5 支撑策略（强制）

- 默认：`关闭支撑`
- 仅当局部悬垂角超过 `55°` 或桥接失败时开启
- 支撑类型：优先“仅接触热床”
- 支撑接触面：启用界面层（建议 `2` 层）
- 支撑与模型间隙：`0.20~0.24mm`

说明：当前型号应优先通过结构设计避免依赖支撑。

### 13.6 速度与加速度（建议基线）

| 项目 | 推荐值 |
|---|---:|
| 首层速度 | `20mm/s` |
| 外墙速度 | `30~35mm/s` |
| 内墙速度 | `45~60mm/s` |
| 填充速度 | `60~80mm/s` |
| 走线（Travel） | `120~180mm/s` |

若设备支持加速度控制，建议先以中等加速度配置运行，确认尺寸稳定后再逐步提速。

### 13.7 精度与公差补偿（强制）

- XY 尺寸补偿（Horizontal Expansion）：建议从 `-0.05mm` 起调
- 首层象脚补偿：建议 `0.15~0.25mm`
- 成品验收基准：
  - 外形尺寸误差：`±0.30mm`
  - 配合关键尺寸误差：`±0.20mm`
  - 翘曲：任一角翘起不得超过 `0.50mm`

### 13.8 打印质量档定义

- `标准档（默认）`：层高 `0.20mm`，按本章节全部基线参数执行
- `精细档`：层高 `0.16mm`，其余参数保持不变
- `草稿档（仅内部验证）`：层高 `0.24mm`，不得用于用户交付样件

## 14. 打印过程控制与质检规范（强制）

### 14.1 打印方向标准（强制）

- 每个 SKU 必须固化一个“标准打印朝向”，并在建模文档中记录
- 同一 SKU 的批量打印不得随意更改朝向
- 涉及配合槽位或孔阵列的 Item，优先使用“槽口朝上”的标准朝向
- 框体类默认以底面贴平台打印，禁止侧躺打印

### 14.2 材料状态控制（强制）

- 打印前 PLA Matte 必须满足干燥条件（推荐 `45~50°C`，`4~6h`）
- 开封耗材必须记录开封日期与累计暴露时长
- 连续打印中若出现明显拉丝突增、表面起泡、噼啪声，必须暂停并重新干燥

### 14.3 设备校准频率（强制）

- 每周至少执行一次：流量校准、压力提前（PA）校准、首层水平检查
- 每批次首件打印前执行一次喷嘴状态检查与平台清洁
- 更换喷嘴、耗材批次或切片参数后，必须重新打印校准样件

### 14.4 桥接与悬垂控制（建议强）

- 对孔口、槽口、长跨距区域启用桥接参数优化
- 建议桥接速度：`20~30mm/s`
- 建议桥接流量：`0.90~0.95`
- 桥接风扇：`100%`
- 若桥接失败率升高，优先调整桥接参数，不优先打开支撑

### 14.5 首件批准流程（FAI，强制）

每个新 SKU 或参数变更后首批打印，必须完成 FAI：

1. 首件打印完成后进行外观与尺寸全检
2. 抽检关键配合尺寸（不少于 3 处）
3. 完成实物装配验证（能放入、能取出、无异常卡滞）
4. 记录并签核后方可批量生产

### 14.6 批量抽检规则（强制）

- 默认抽检频率：每 `10` 件抽 `2` 件
- 框体类最少抽检项：
  - 外轮廓长宽
  - 底部平面翘曲
  - 关键边高（前沿/后沿）
- Item 类最少抽检项：
  - 外形尺寸
  - 槽位关键尺寸
  - 边缘缺陷（崩边、毛刺）

### 14.7 外观质量分级（强制）

- A 级：可直接交付；无明显拉丝、无明显接缝突起、顶面均匀
- B 级：轻微外观缺陷，可内部使用或返工后交付
- C 级：不可交付，需返工或报废

判定为 C 级的典型问题：

- 关键配合区域缺料或塌边
- 关键尺寸超差
- 翘曲超出本规范验收阈值

### 14.8 返工与报废判定（强制）

- 可返工项：轻微毛刺、可去除拉丝、非关键面轻微接缝突起
- 不可返工项：关键槽位超差、结构开裂、明显层间分离、底面翘曲超限
- 返工后必须复检关键尺寸和装配功能

### 14.9 打印环境控制（建议强）

- 建议环境温度：`22~30°C`
- 避免打印机受空调直吹或强对流风影响
- 保持平台与打印区域清洁，防止粉尘导致首层附着不稳

### 14.10 参数锁定与变更日志（强制）

- 当前基线切片参数必须保存为“生产配置文件”
- 未更新变更日志前，不得修改生产配置文件用于批量打印
- 任一参数变更必须记录：变更项、原因、验证结果、执行日期、责任人
