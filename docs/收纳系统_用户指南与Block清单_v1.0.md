# 通用收纳系统用户指南与 Block 清单 v1.0

## 1. 系统简介

这是一个可拼装、可扩展的收纳系统，核心规则如下：

- 统一网格：每个基础单元为 `40 x 40mm`
- 标准 Block：`240 x 160mm`，可理解为 `6 x 4` 个网格
- 普通框体最大：`240 x 160`；挂墙框体最大：`240 x 120`
- 支持多框体规格：`240x160`、`240x120`、`240x80`、`160x160`、`160x120`、`160x80`、`160x40`、`80x40`
- 标准高度：`20 / 40 / 80mm`
- 增高件：`5 / 10 / 20mm`，用于制造前低后高的取物坡度
- 支持 IKEA 洞洞板挂载（兼容型号以清单标注为准）

## 2. 选型方法（3 步）

1. 按物品长宽选择占格（`1x1`、`2x1`、`2x2` 等）
2. 按物品高度选择 `H20 / H40 / H80`
3. 按使用习惯选择紧凑收纳或易取优先

### 2.1 5 位短编号怎么读

短编号格式：`TTSNN`

- `TT`：前两位，表示类型（例如通用收纳、笔筒、电池、口红、增高件）
- `S`：第 3 位，表示系列
- `NN`：后两位，自增流水号（`01~99`）

示例：`11002` 表示通用收纳类型下某系列的第 2 个型号。

## 4. 典型场景推荐

### 4.1 标准收纳区（通用）

- 建议编号：`11001`、`11002`、`11003`
- 适合物品：零散配件、转接头、小工具

### 4.2 笔筒区

- 建议编号：`12001`、`12002`
- 建议布局：后排高筒，前排低矮通用格

### 4.3 电池区

- 建议编号：`21001`、`21002`
- 建议布局：预留一个空格用于“待充/已充”状态分区

### 4.4 口红区

- 建议编号：`22001`、`22002`
- 建议布局：后排适当增高，提升可视与拿取效率

### 4.5 挂墙收纳区（IKEA 洞洞板）

- 建议编号：`42001/42002/42003` + `11001`、`11002`、`12001`
- 建议布局：高频件放中下区，重件靠近挂载中心区
- 注意：挂墙使用时请优先查表中标注的兼容板型与建议载荷

## 5. 增高件使用建议

- 增高层数不建议超过 `2` 层
- 推荐后排比前排高 `10~15mm`
- `5mm` 增高优先用于轻载场景
- 重物场景建议使用一体式高件，避免过度叠加

## 6. 新手入门组合（建议）

可从以下组合开始（覆盖文具、电池和日常小物）：

- 通用格：`11001 x4`
- 通用格：`11002 x4`
- 通用格：`11003 x2`
- 笔筒：`12001 x2`
- 电池：`21001 x2`
- 口红：`22001 x2`
- 增高：`31004 x4`
- 增高：`31005 x2`

## 7. 使用提示

- 想要高密度：优先紧凑槽位设计
- 想要好拿取：优先易取槽位设计
- 经常拿取的物品，建议放在前排和中排
- 高件建议放后排并配合增高件形成高度梯度
