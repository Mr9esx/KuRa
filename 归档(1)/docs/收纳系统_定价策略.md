# 收纳系统定价策略（内部）

## 1. 目标

本策略用于统一框体、Item、套装和活动定价，确保：

- 用户容易理解并愿意下单
- 套装有明确性价比，单买也不亏
- 定价可覆盖包装、运费、电费、损耗与售后风险

## 2. 成本口径（当前）

### 2.1 材料单价

- 耗材价格：`35 元 / 1.1kg`
- 换算单价：`0.03182 元/g`

### 2.2 材料成本估算

- 标准框体（240x160）：`250~290g` → `7.95~9.23 元`
- 1 套（1框体+12 Item）：`600~895g` → `19.1~28.5 元`
- 套装材料核算基线：建议取 `24 元`

### 2.3 履约与运营成本（建议纳入）

以 1 套为口径建议按下列项目计入：

- 包材（箱+缓冲+贴纸）：`6~8 元`（建议按 `7` 计）
- 打印电费：`3~5 元`（建议按 `4` 计）
- 设备磨损/维护摊销：`2~4 元`（建议按 `3` 计）
- 打印损耗与不良摊销：按小计的 `8%~12%`（建议 `10%`）

基于以上，套装不含运费综合成本约：

- 小计：`24 + 7 + 4 + 3 = 38`
- 加损耗（10%）：`3.8`
- **不含运费综合成本：约 `42 元`**

## 3. 运费策略（必须先定）

### 3.1 买家承担运费（推荐）

- 店铺售价不含邮费，结算页按地区收运费
- 优点：价格更有竞争力，毛利结构更稳

### 3.2 卖家包邮

- 套装建议预留运费：`8~12 元/单`（建议按 `10` 计）
- 包邮后套装综合成本约：`52 元`

## 4. 定价原则

1. 单买价格是锚点，套装必须有清晰优惠
2. Item 必须按复杂度分层，不做全 9.9
3. 活动优先打套装，单件尽量少打折
4. 定价至少覆盖“综合成本 + 风险缓冲”

## 5. 推荐价格（已按新成本调整）

### 5.1 框体

- 标准框体：`45`
- 挂墙版或带挂件版：`49`

说明：框体材料虽然降了，但单独出货仍有包材、电费、损耗与售后成本，`45` 仍是稳妥主销点。

### 5.2 Item 三档

- 基础款：`9.9`（浅槽、低复杂）
- 标准款：`14.9`（常规孔阵列、电池/卡类）
- 专业款：`19.9`（深槽、复合结构、高精度）

### 5.3 套装（1框体+12 Item）

- 不包邮日常价：`129`
- 不包邮活动价：`119`
- 包邮日常价：`139`
- 包邮活动价：`129`
- 双套装建议价：`239`（不包邮）/`259`（包邮）

## 6. 为何不是继续降价

虽然材料成本下降约 `29%`，但真实成本并不只看材料：

- 包材、电费、设备磨损、损耗和售后不会同步下降
- 如果直接按材料降价，后续扩品和售后会被利润挤压
- 维持当前价格带更利于长期稳定运营

## 7. 毛利快算（便于决策）

### 7.1 套装（不包邮）

- 成本基线：`42`
- 售价 `119`：毛利额 `77`，毛利率约 `64.7%`
- 售价 `129`：毛利额 `87`，毛利率约 `67.4%`

### 7.2 套装（包邮，按运费 10）

- 成本基线：`52`
- 售价 `129`：毛利额 `77`，毛利率约 `59.7%`
- 售价 `139`：毛利额 `87`，毛利率约 `62.6%`

### 7.3 框体单卖（简化）

- 综合成本（材料+电费+包材+损耗）：约 `15~19`
- 售价 `45`：毛利空间充足，可覆盖平台扣点和售后

## 8. 执行建议（30 天）

### 第 1 阶段（上线）

- 不包邮场景：套装 `129`，活动 `119`
- 包邮场景：套装 `139`，活动 `129`
- 框体：`45`
- Item：`9.9 / 14.9 / 19.9`

### 第 2 阶段（验证）

- 重点看：套装转化、单买占比、补件复购
- 若单买过多：强化“套装省 xx 元”信息

### 第 3 阶段（微调）

- 高复杂低销量 Item 优先提价，不优先降价
- 促销集中在套装，避免单件价格体系被打乱

## 9. 最终建议

在新成本口径下，**更优策略不是盲目降价，而是保持价格体系稳定并把履约成本算清**。建议执行：

- 框体 `45`
- Item `9.9 / 14.9 / 19.9`
- 套装：
  - 不包邮：`129`（活动 `119`）
  - 包邮：`139`（活动 `129`）

这套方案既反映了材料降本，也预留了打包、运费、电费与损耗空间。
